## v0.1.0 — August 13, 2026

- Added `sigilmd.pl`: a single core-Perl script that scans a Markdown file for `<!--[[ name ]]-->` table declarations and `<!--[[ $table.key ]]-->` / `<!--[[ @table.key ]]-->` reference markers and splices the resolved values or file contents back in place — no template language, no CPAN dependencies
- Added a small TOML subset for table bodies: one `key = "value"` pair per line, everything a string, blank lines and `#` comments ignored
- Added chained references (`$a.b$c.d`, `@$a.b$c.d`) — juxtaposed `$table.key` lookups concatenated with no separator, optionally read from disk as a file path when the marker starts with `@`
- Added external TOML config files (`--config`), merged into the same table namespace as inline declarations, with a hard error on a name declared in both places
- Added `--check` for CI: exits non-zero without writing anything when the file is out of date
- Added `action.yml`, a composite GitHub Action wrapping the script — no interpreter setup step, since GitHub-hosted runners ship Perl natively — plus `commit`/`commit-message`/`commit-user-name`/`commit-user-email` inputs and a `changed` output, matching the other projects in this suite
- Added a CI workflow that runs the test suite across a matrix of Perl versions back to 5.8, a composite-action end-to-end run against a scratch fixture, and dogfooding jobs that verify the README's project-structure tree (via treegen2) and badges (via sigilbadges) are current
- Added a fixture-based test suite (`perl t/run.pl`) covering the happy path and idempotency of repeated runs
- Added the project site (`index.html`, `docs.html`, this changelog) with the suite's blue branding
- Crossed with the other two projects in this suite: the README's badges are generated by sigilbadges and its project-structure tree by treegen2, the same way sigilbadges' own README is kept current by treegen2
